# Ride-Hailing App

Ride-hailing app simulation in C++ with users, drivers, premium drivers and orders.

## Features

- Register users and drivers (regular and premium)
- Create orders and calculate fares
- Discount for Gold-tier users

## How to run

```bash
g++ ride_hailing_app.cpp -o ride_hailing_app
./ride_hailing_app
```

## About

Built in **C++** for the OOP Practicum - assignment 2 course, Robotics and Artificial Intelligence Engineering.
